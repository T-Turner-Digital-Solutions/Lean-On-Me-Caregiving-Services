# Image assets

Place polished, licensed caregiving imagery here.

| File in this folder     | Used by                                         |
| ----------------------- | ----------------------------------------------- |
| `lean-on-me-hero.jpg`   | Hero poster / fallback + Open Graph share image |

## Requirements
- **`lean-on-me-hero.jpg`** — a high-resolution, warm, dignified caregiving
  photograph. Recommended 1920×1080 (16:9), optimized JPG under ~300 KB.
  It appears instantly as the hero poster while the video loads and is the
  fallback if the video cannot play. It is also the social-share (Open Graph)
  image referenced in `index.html`.

Use only imagery you are licensed to use. Avoid stocky, clinical photos —
prefer warm, human, respectful moments consistent with the luxury aesthetic.
